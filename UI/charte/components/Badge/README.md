# Badge

Un ou deux mots d'information à côté d'un média, d'un clip ou d'un rendu.

- **Fourni par l'appelant** : le texte, le ton, et pour un état une icône Lucide de 12 px.
- Tons : neutre (format, codec), `rm-badge-accent` (effet actif), `rm-badge-anim` (paramètre animé, modulateur), `rm-badge-success`, `rm-badge-warning`, `rm-badge-danger` pour les états, toujours avec icône et mot.
- Style `caption`, hauteur 20 px, arrondi `radius-xs`.
- À éviter : un badge décoratif, un état signalé par la couleur seule.
