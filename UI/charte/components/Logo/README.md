# Logo

Le logo de Remanence : le symbole Tranches, un disque découpé en cinq tranches décalées dont une en mauve, suivi du nom en IBM Plex Sans 600.

- **Fourni par l'appelant** : la taille (`font-size` sur `rm-logo` ; le symbole fait 1,15 fois la hauteur du texte, écarté de 0,36 em) et le fond, qui décide du fichier.
- Fichiers du dossier `assets/Logos` : `remanence-symbole.svg` sur fond sombre (tranches `ink` sombre et mauve), `remanence-symbole-clair.svg` sur fond clair, `remanence-symbole-mono.svg` pour une seule encre, `remanence-icone-petite.svg` (trois tranches, plus lisible) à 20 px et moins.
- Icône d'application : le symbole sur `surface-raised`, carré aux angles arrondis, symbole à 65 % du côté.
- Le nom s'écrit toujours « Remanence », majuscule initiale, sans accent, dans les deux langues.
- À éviter : recolorer les tranches, en ajouter, animer le symbole dans l'interface, déformer le disque, poser le logo sur une image chargée sans fond.
